# Security & Network Testing Guide

An end-to-end method for running authorised security and network assessments, from written authorisation and scoping through active testing to the final report. Built around Parrot OS on the command line, with Windows and Zenmap equivalents.

**[Open the guide (PDF)](Security_Network_Testing_Guide.pdf)**

## What's inside

| Part | Covers |
| :--- | :--- |
| 1 — Pre-engagement & scoping | Authorisation, scope questions, rules of engagement, what to avoid |
| 2 — Methodology overview | The five phases and why each one matters |
| 3 — Passive reconnaissance | Public-source information gathering without touching the target |
| 4 — Active scanning | Staged host discovery, port sweeps, service and OS detection |
| 5 — Vulnerability assessment | Mapping services to known vulnerabilities |
| 6 — Validation | Controlled confirmation of findings, only with explicit permission |
| 7 — Reporting | Turning results into a clear, evidence-backed deliverable |
| 8 — NSE script reference | Nmap scripts grouped by service |
| 9 — Metasploit quick workflows | Workspace setup, importing scans, checking findings |
| 10 — Remediation playbook | Common findings and how to fix them |
| Appendices | Client intake and scope form, findings log, final report template, command quick reference |

## How each phase is laid out

Every phase covers its goal, prerequisites, copy-ready commands, what a good result looks like, common mistakes, and exactly what to record for the report.

## Responsible use

Everything in this guide is for systems you own or have **written authorisation** to test. Unauthorised testing may be a criminal offence.

Companion to the [Technician's Field Guide](https://github.com/W1CK3DSYST3MS/Technicians-Field-Guide), which covers fault diagnosis rather than assessments.
